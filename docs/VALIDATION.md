## 已知边界

本工具显示本地日志中的历史额度快照，不提供服务器主动查询。没有新日志时无法得到更新后的额度。运行期间不联网。

扫描每个文件最多回溯 64 MB，单行上限 4 MB。日志格式是 Codex 内部实现，未来版本变化可能需要适配。单目录多账号日志无法可靠区分账号。

开机启动注册表写入默认关闭，未为测试修改用户开机启动设置。未进行数天常驻或 Windows 重启后的实机验证。
